**Маршрутизация курьерской доставки**

**Запрос для создания тестовых данных**
Запрос: `POST /api/test` (без тела) автоматически создает полную цепочку объектов с `ID = 1` (Пользователь -> Маршрут -> Отправление -> Остановка -> Назначение).

**CRUD операции**
*   `GET {путь}` — чтение массива объектов
*   `GET {путь}/{id}` — чтение одного объекта
*   `POST {путь}` — создание объекта
*   `PATCH {путь}/{id}` — частичное обновление объекта
*   `DELETE {путь}/{id}` — удаление объекта

| Сущность         | Базовый путь                | Особенности при создании (POST)                       |
| :--------------- | :-------------------------- | :---------------------------------------------------- |
| **Пользователь** | `/api/users`                | Передаются только поля объекта в JSON                 |
| **Маршрут**      | `/api/routes`               | Передаются только поля объекта в JSON                 |
| **Отправление**  | `/api/shipments`            | Требует параметр в URL: `?senderId={id}`              |
| **Остановка**    | `/api/stops`                | Требует параметр в URL: `?routeId={id}`               |
| **Назначение**   | `/api/shipment-assignments` | Требует два параметра: `?shipmentId={id}&stopId={id}` |
